# AuraAscend: Predator-Grade Health HUD

A real-time, immersive health and productivity dashboard designed with a high-performance gaming aesthetic.

## 🔗 Deployed URL
https://dcain99.github.io/aura-ascend-final/

## 🛠️ Features
* **Dynamic Aura Scaling:** Visual feedback and ranking based on health data.
* **Real-Time Analytics:** Interactive charts using Chart.js to track 7-day trends.
* **Immersive Audio:** Web Audio API integration for ambient system feedback.
* **Persistence:** LocalStorage integration to save data across sessions.

## 🚀 How to Run
1. Download the ZIP file.
2. Extract the contents.
3. Open `index.html` in any modern web browser (Chrome or Edge recommended).
